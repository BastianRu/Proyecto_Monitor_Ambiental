Detailed Description

Declaración de estados, señales de entrada y prototipos de la FSM.

Define los 7 estados (State), las 13 señales de entrada (Input) que disparan transiciones, y los prototipos de los callbacks de entrada/salida de cada estado.

Authors
Juan Sebastian Muñoz Ruiz, Andrea Fernanda Gomez, Daniel Alexander Chaguendo

◆ State

enum State

Estados posibles de la máquina de estados finita (FSM).

Enumerator
Inicio 

Estado inicial: solicita clave y/o tarjeta RFID.

Config 

Modo administrador: activado por botón físico.

MonitorAmbiental 

Monitoreo continuo de temperatura y luz.

MonitorPuertas 

Monitoreo de intrusos (sensor Hall y micrófono).

Alarma 

Alarma activa: LED rojo parpadeante y buzzer.

Bloqueo 

Sistema bloqueado tras 3 intentos fallidos.

Gestion 

Gestión: se alcanzaron 3 alarmas consecutivas en 12 s.

◆ Input

enum Input

Señales de entrada que disparan transiciones en la FSM.

Enumerator
SIG_CLAVE_CORRECTA 

Clave + UID válido + horario correcto → MonitorAmbiental.

SIG_BOTON 

Botón físico presionado: Inicio → Config.

SIG_TECLA_HASH 

Tecla '#': Config → Inicio.

SIG_TECLA_ASTERISCO 

Tecla '*': Gestion → Inicio.

SIG_ALARMA_COND 

Temp > umbral o Luz > umbral → Alarma.

SIG_INTRUSOS 

Hall o Mic activo (activación detectada) → Alarma.

SIG_TIMEOUT_AMBIENT 

Timeout 3 s en Alarma → MonitorAmbiental.

SIG_TIMEOUT_INTRUS 

Timeout 4 s en Alarma → MonitorPuertas.

SIG_ACTIVACIONES 

3 alarmas consecutivas en 12 s → Gestion.

SIG_TIMEOUT_INTRUS2 

Timeout 2 s en MonitorPuertas → MonitorAmbiental.

SIG_TIMEOUT_AMB_TO_INT 

Timeout 5 s en MonitorAmbiental → MonitorPuertas.

SIG_BLOQUEADO 

3 intentos fallidos de clave → Bloqueo.

SIG_TIMEOUT_BLOQUEO 

Timeout 7 s en Bloqueo → Inicio.

SIG_UNKNOWN 

Señal nula / sin evento pendiente.
