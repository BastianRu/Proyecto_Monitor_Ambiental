Detailed Description

Definición de pines, constantes de hardware y temporización para Arduino Mega 2560.

Centraliza todos los números de pin, umbrales de sensor, tiempos de tarea y límites lógicos del sistema. Modificar este archivo es suficiente para adaptar el firmware a un hardware diferente.
